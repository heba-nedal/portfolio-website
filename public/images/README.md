# Portfolio image paths

Add your own images at these exact paths; missing images keep their placeholders.

- `profile-photo.jpg`: your portrait (4:5 area, top-aligned cover crop).
- `graduation-certificate.jpg`: your official certificate (contained, not cropped).
- `projects/cmwu.jpg`
- `projects/freelango.jpg`
- `projects/edukate.jpg`
- `projects/workshop-automation.jpg`

Project screenshots use a consistent 16:9 area with top-aligned cover cropping. A 1600 × 900 screenshot fits without cropping; taller images crop at the bottom. Use only public-safe screenshots with private data removed.

All image URLs are defined in `src/content/portfolioContent.ts`. No fake screenshots are included. The workshop project has no verified contribution or feature list; its dialog shows its documented solution and workflow instead of inventing them.
